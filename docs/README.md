# Stu Public Documentation

This directory contains sanitized documentation intended for public portfolio review.

## Contents

- [`stu-architecture.svg`](stu-architecture.svg) — high-level architecture showing the path from academic input through authoritative local state to planning, recommendations, feedback, and visualization.
- [`verification.md`](verification.md) — public verification overview distinguishing the 74/74 release-candidate automated baseline from later strict audits and separate manual acceptance.

## Scope

The public documentation intentionally omits proprietary source code, private academic data, detailed fixtures, raw test artifacts, internal audit records, and implementation-specific operational material.

The canonical Stu application and its complete engineering record are maintained privately.
